Hay una idea muy común: construir una web es como mandar a imprimir un folleto. Se diseña, se publica y el trabajo queda terminado.

Una web no funciona así. Es un sistema que está conectado todo el día a internet, con navegadores, servidores, medios de pago y buscadores que cambian con el tiempo. Pensar que no necesita atención después de publicarla es como comprar un vehículo y no hacerle mantención: puede funcionar un tiempo, pero tarde o temprano se detiene, muchas veces en el peor momento.

## 1. El entorno cambia aunque tú no toques tu web

Hay tres razones por las que una web puede dejar de funcionar bien sin que nadie la modifique:

- **Los navegadores se actualizan.** Chrome, Safari, Edge y Firefox cambian sus reglas de rendimiento y privacidad. Algo que hoy se ve bien en un celular puede verse distinto después de una actualización.
- **Los servidores también se actualizan.** Los centros de datos cambian sistemas y versiones para ser más rápidos y seguros. Si tu web usa una tecnología que el servidor ya no soporta, puede dejar de cargar.
- **Aparecen nuevos dispositivos.** Cada año hay pantallas con tamaños y formas distintos. Mantener una buena experiencia exige revisarla de vez en cuando.

## 2. La seguridad no avisa cuando se debilita

Una web desatendida no muestra una alerta cuando empieza a tener un problema. Gran parte de los ataques son automáticos: programas que recorren muchas páginas buscando fallas conocidas.

Las herramientas que usa tu web, como el sistema de gestión de contenidos, los formularios, las galerías o la tienda, reciben correcciones de seguridad con frecuencia. Si no aplicas esas actualizaciones, las fallas quedan abiertas.

Un sitio sin cuidado rara vez se apaga de inmediato después de un ataque. Lo más común es que siga funcionando mientras redirige visitas a páginas dudosas, se vuelve lento o envía correos falsos en nombre de tu dominio. Cuando te das cuenta, la reputación de tu marca ya se vio afectada.

Además, los navegadores pueden advertir a las personas que una web es insegura. Si eso pasa, es probable que pierdas visitas antes de que alguien llegue a leer tu propuesta.

## 3. Las piezas de una web dependen unas de otras

Una web moderna no es una sola pieza. Está formada por varias partes que se conectan:

- El sistema principal del sitio.
- Los complementos que agregan funciones, como el carrito, el formulario, el chat o los botones de redes sociales.
- Los servicios externos, como los medios de pago, el correo o la facturación.

Si pasan muchos meses sin revisión y de pronto se actualiza todo al mismo tiempo, algo puede dejar de funcionar. Un complemento nuevo puede no llevarse bien con otro que lleva mucho tiempo sin actualizarse, y el resultado puede ser un formulario que no envía o un pago que no se completa.

La mantención preventiva evita ese problema: actualiza por etapas, revisa cada cambio y comprueba que todo siga funcionando en conjunto.

## 4. La velocidad también se desgasta

Con el uso diario, una web acumula material que ya no sirve: versiones antiguas de textos, sesiones vencidas, carritos abandonados y registros que nadie revisa. Si nunca se limpia, la base de datos se vuelve más pesada y las páginas tardan más en responder.

Una web lenta hace que más personas se cansen de esperar y se vayan. Por eso conviene revisar la velocidad cada cierto tiempo.

## 5. Las copias de respaldo son la red de seguridad

Un servidor puede fallar, un proveedor puede tener problemas técnicos o alguien puede borrar información por error. La mantención responsable incluye copias de respaldo periódicas, completas y guardadas fuera del servidor donde está tu web.

Así, si algo sale mal, no empiezas de cero. Puedes recuperar tu sitio tal como estaba. En [copias de seguridad de tu web con GitHub y Railway](/blog/copias-de-seguridad-web-github-railway/) explicamos qué debe incluir un respaldo completo.

## Tu web como activo del negocio

Muchas veces la web es el primer contacto entre tu empresa y un cliente que está por decidir. Mantenerla en buen estado no es un gasto que se pueda postergar: es proteger el lugar donde se encuentra tu negocio.

Una rutina simple de revisión, actualización y respaldo permite que tu web cargue bien, proteja los datos de quienes la visitan y siga atendiendo a clientes todos los días. Si quieres estimar cuánto cuesta esa rutina, en [cuánto cuesta mantener una web en WordPress para tu pyme](/blog/costo-mantener-web-wordpress-pyme/) revisamos los costos.

## En resumen

Una web cambia aunque no la toques. Los navegadores, los servidores, la seguridad y los complementos evolucionan, y la base de datos se va llenando. La mantención preventiva evita sorpresas: revisa, actualiza por etapas y respalda fuera del servidor. Así la web sigue funcionando cuando más la necesitas.
