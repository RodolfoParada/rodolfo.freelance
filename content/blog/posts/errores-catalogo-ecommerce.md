Nada le quita más confianza a una tienda online que un catálogo que no funciona. El cliente elige una polera azul y aparece una verde. Escoge la talla L y el precio cambia sin explicación. O el botón de compra queda bloqueado con un mensaje de «combinación no disponible».

Muchas veces el problema no es la plataforma, sino cómo se armó el catálogo desde el principio. Y estos errores también afectan a Google y a las campañas de publicidad, porque dependen de datos consistentes.

## Un producto con variaciones, no varios productos

Un error frecuente es crear una publicación distinta para cada talla o color. Por ejemplo, una para «Zapatilla Modelo A talla 39», otra para la talla 40 y otra para la 41.

El problema es que las visitas se reparten, las opiniones se dividen y el cliente tiene que volver atrás para ver si queda su talla.

Lo más conveniente es crear un producto principal, con variaciones dentro de él para cada talla o color. Así toda la información se concentra en una sola página.

## Los atributos deben tener nombres iguales

Si un color aparece como «azul marino» en un producto, «azul oscuro» en otro y «blue» en un tercero, los filtros del catálogo se vuelven confusos. Si el cliente filtra por «azul marino», se pierden los productos con los otros nombres.

Define una lista de nombres oficiales para colores, tallas y materiales, y úsala siempre igual.

## La foto debe cambiar con la variación

Si el cliente elige «negro titanio», la imagen principal debería mostrar ese color. Cuando la foto no cambia, el cliente duda de si recibirá lo que eligió.

## Oculta lo que no tiene stock

Si muchas combinaciones aparecen disponibles pero no hay unidades, el cliente hace clic en varias opciones, se frustra y se va.

Conviene ocultar las variantes sin inventario, o al menos marcarlas claramente como agotadas.

## Cada variante necesita su propio código

Cada variación debe tener un código SKU único. Si dos tallas comparten el mismo código:

- Bodega puede embalar una talla por otra.
- La facturación puede registrar salidas de stock equivocadas.
- Algunas plataformas de venta pueden rechazar el catálogo por códigos repetidos.

## Revisa el catálogo antes de hacer publicidad

Antes de lanzar una campaña a una categoría, revisa algunos puntos:

- ¿Cada color y talla tiene su propio código?
- ¿La foto cambia al elegir una variación?
- ¿El precio cambia cuando debe cambiar?
- ¿Los filtros muestran nombres sin duplicados?
- ¿Las opciones agotadas están marcadas?

Un catálogo ordenado casi no se nota. Cuando falla, en cambio, las ventas caen de inmediato.

## En resumen

Los errores de catálogo suelen venir de decisiones tomadas al crear los productos: variaciones mal organizadas, nombres distintos para lo mismo, fotos que no coinciden y códigos repetidos. Corregirlos toma tiempo, pero evita dolores de cabeza con clientes, bodega y publicidad.
